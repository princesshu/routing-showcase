# Internationalization

Astro's i18n routing maps locales to URL prefixes, tells each page which locale it is rendering, and can fall back to another locale when a page is missing.

**In this repo:** English is the default locale at the root, German lives under `/de/`. `src/pages/greeting.astro` and `src/pages/de/greeting.astro` are the two versions of one page. `src/pages/farewell.astro` has no German version.

## Configuration

```ts
// astro.config.ts
i18n: {
  locales: ['en', 'de'],
  defaultLocale: 'en',
  routing: { prefixDefaultLocale: false, fallbackType: 'redirect' },
  fallback: { de: 'en' },
},
```

```
src/pages/
├─ greeting.astro   → /greeting       (en)
├─ farewell.astro   → /farewell       (en)
└─ de/
   └─ greeting.astro → /de/greeting   (de)
                       /de/farewell   fallback to /farewell
```

## In a page

```astro
---
import { getRelativeLocaleUrl } from 'astro:i18n';
---

<p>
  Current locale: <code>{Astro.currentLocale}</code>
</p>
<a href={getRelativeLocaleUrl('de', 'greeting')}>Deutsch</a>
```

`Astro.currentLocale` comes from the URL. `getRelativeLocaleUrl()` builds the localized path, so the prefix rules live only in the config.

## Fallback

With `fallback: { de: 'en' }`, a URL under `/de/` without its own page shows the English page instead of a 404. `fallbackType` decides how:

- **`redirect`** (used here) sends the visitor to `/farewell`.
- **`rewrite`** renders the English page at `/de/farewell`, so the URL stays German.

## Good to know

- **The fallback applies to every page.** The build writes a `/de/` twin for each prerendered page without a German version, `/de/about` and `/de/products/1` included. With `rewrite`, every twin is a full copy of the English page. On-demand pages fall back at request time instead: `/de/files/x` answers with a 302 to `/files/x`.
- **A static fallback redirect is a meta refresh.** For prerendered pages, the twin is an HTML file with `<meta http-equiv="refresh">` and a 2 second delay, served with status 200, not a 3xx response. Crawlers see a `noindex` tag and a canonical link to the English page.
- **The `de` folder is a real segment.** It is not a route group: `src/pages/de/greeting.astro` is matched like any other file. The i18n config only adds the locale logic and the fallbacks around it.

Reference: [Internationalization (i18n) Routing](https://docs.astro.build/en/guides/internationalization/)
